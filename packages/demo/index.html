Nothing leaves this device

Nights recorded here stay in this browser on this device. Clearing site data removes them. This demo runs the full detection pipeline from the @bugtracker/surveillance library with no server at all.

If the screen keeps sleeping

This page asks the device to stay awake on its own, so usually there is nothing to do. If it sleeps anyway, the camera stops and the rest of the night is lost — set it manually once:

  • iPhone or iPad: Auto-Lock to Never, and Low Power Mode off — it blocks the screen lock on its own.
  • Android: Screen timeout to its longest option.
  • Laptop: turn off screen sleep in your system power settings.
  • Keep it plugged in either way — a screen held on all night will flatten a battery.
